# Claude Code config file

At the start of every session, read [Agent Lessons and Working Rules](docs/agent-lessons.md)
before substantive work. Maintain that log when material mistakes or communication
lessons arise; keep entries concise and avoid duplicates.

Then use [README.md](README.md) for the project overview and documentation map.
Read only the documents and sections relevant to the current task.

Read [functional requirements](docs/requirements.md) for task and project behavior,
[UI specifications](docs/ui.md) for interactions and layouts, and
[development requirements](docs/development.md) before implementation work.

Window templates live in `docs/templates/`. C coding and implementation guidance
live in `docs/developer/`. Read the [ncurses implementation notes](docs/developer/ncurses-ui.md)
before working on terminal rendering, layout, or input handling.

The approved implementation plan (module breakdown, schema, 17+ step build
order, and current progress status) lives in
[docs/developer/implementation-plan.md](docs/developer/implementation-plan.md).
Read its Status section before starting or resuming implementation work, and
add new steps there instead of only discussing them in a session.
